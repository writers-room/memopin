메모핀 0.1.0 · 한정 배포

바탕화면에 붙이는 스티커 메모, 메모핀

윈도우 스티키 메모의 느낌을 그대로 두고, 계정과 동기화 설정을 걷어낸 개인용 메모 앱입니다. 메모 하나가 창 하나이고, 메모함에서 카테고리·즐겨찾기·휴지통으로 관리합니다. 이 페이지는 초대받은 분들께만 드리는 안내입니다.

윈도우 설치 파일 · 4.9MB 맥 dmg · 11MB · Apple Silicon/Intel
Windows 10/11 · macOS 12 이상 · 자동 업데이트 포함 · 2026년 9월 5일

설치

Windows

  1. 설치 파일을 실행합니다. 몇 초면 끝나고 바로 실행됩니다.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다. 코드 서명 인증서를 사지 않은 개인 배포라 그렇습니다. 파일은 GitHub에서 빌드된 그대로입니다.
  3. 설치 위치는 사용자 폴더 안(%LOCALAPPDATA%\메모핀)이라 관리자 권한이 필요 없습니다.

macOS

  1. dmg를 열고 메모핀을 응용 프로그램 폴더로 끌어 넣습니다.
  2. 첫 실행만 응용 프로그램 폴더에서 아이콘을 우클릭 → 열기로 엽니다. "확인되지 않은 개발자" 경고는 Apple 개발자 계정 없이 서명했기 때문이고, 한 번 열면 다음부터는 그냥 실행됩니다.
맥에서 "손상되어 열 수 없습니다"가 뜨면 터미널에서 xattr -dr com.apple.quarantine /Applications/메모핀.app을 한 번 실행한 뒤 다시 열어 주세요. 인터넷에서 받은 앱에 붙는 격리 표시를 떼는 명령입니다.

첫 실행

실행하면 작업표시줄에 메모핀 창(메모함)이 뜨고, 트레이(시계 옆)에 노란 아이콘이 올라옵니다. 처음에는 사용법을 적은 안내 메모 두 장이 바탕화면에 펼쳐져 있습니다. 읽고 나면 지워도 되고, 다시 생기지 않습니다.

메모함 창 ✕

창만 숨깁니다. 메모는 그대로이고 트레이 아이콘을 누르면 다시 나옵니다.

메모 창 ✕

바탕화면에서만 치웁니다. 메모함에 남아 있고 언제든 다시 펼칠 수 있습니다. 아무것도 안 적은 빈 메모는 그냥 사라집니다.

완전히 끄기

트레이 아이콘 우클릭 → 종료. 펼쳐 둔 메모는 다음 실행 때 같은 자리에 돌아옵니다.

어디서든 새 메모

Ctrl+Shift+N. 다른 프로그램을 쓰는 중에도 새 메모가 뜹니다(설정에서 끄거나 바꿀 수 있습니다).

메모 창

메모 창에는 제목줄이 없습니다. 위쪽 가장자리에 마우스를 올리면 손잡이가 나타나고, 그 부분을 끌어 옮깁니다. 첫 줄이 곧 메모함에서 보이는 제목입니다.

이렇게 치면이렇게 됩니다
- 또는 * 동그라미 글머리 목록. Enter로 다음 항목, 빈 항목에서 Enter를 한 번 더 치면 목록이 끝납니다.
1. 숫자 목록. 번호는 자동으로 이어집니다.
[] 체크박스. 네모를 클릭하면 완료(취소선). 빈 체크 항목에서 Backspace를 치면 체크박스가 빠집니다.

한 번 클릭 · 두 번 클릭

한 번 클릭하면 오른쪽에서 바로 고치고, 두 번 클릭하면 바탕화면에 펼칩니다. 오른쪽 위 버튼으로도 펼치고 닫습니다.

카테고리

"＋ 새 카테고리"로 만들고, 더블클릭으로 이름을 바꾸고, 우클릭으로 지웁니다. 지우면 안의 메모는 미분류로 갑니다.

즐겨찾기 · 상단 고정

목록의 ★는 즐겨찾기 보기에 모입니다. 편집 칸의 📌는 "목록 상단에 고정"이라 창의 "항상 위"와 다릅니다.

여러 개 고르기

Ctrl+클릭으로 더하고 빼고, Shift+클릭으로 범위. 오른쪽에 "N개 선택됨"이 뜨고 한꺼번에 휴지통으로 보내거나 Delete를 칩니다.

휴지통

지운 메모는 휴지통 보기에 남습니다. 우클릭으로 복원하거나 완전히 지우고, "휴지통 비우기"로 한꺼번에 비웁니다.

검색

위 검색칸에 치면 제목·본문·이미지 파일명에서 바로 걸러집니다.

이미지 메모

참고 이미지를 바탕화면에 붙여 두는 용도입니다. 표지 시안, 지도, 캡처한 자료 같은 것들이요.

  • 1가져오기 — 메모함의 🖼 버튼으로 파일을 고르거나, 스크린샷을 찍고 메모함에서 Ctrl+V.
  • 2자르기 — 사각형을 끌어 필요한 부분만 남기고 "만들기". 그대로 쓰려면 "자르지 않고 그대로".
  • 3창 — 가로 320으로 열리고, Ctrl+휠이나 모서리로 키워도 비율이 유지됩니다. 손잡이는 그림 위에 겹쳐 뜹니다.
  • 4곁들인 글 — 메모함 편집 칸에서 그림 아래에 메모를 적을 수 있습니다. 창에는 그림만 보입니다.
이미지 메모 창을 마우스로 가리켰을 때. 지원 형식은 png · jpg · gif · webp · bmp, 20MB까지입니다.

동기화와 백업

메모핀에는 계정이 없습니다. 대신 메모 저장 폴더를 클라우드 폴더로 옮기면, 그 서비스의 데스크톱 프로그램이 동기화를 대신합니다. 구글 드라이브·Dropbox·OneDrive·iCloud Drive 모두 같은 방식입니다.

  1. 그 서비스의 데스크톱 프로그램이 설치되어 있고 폴더가 이 PC에 보이는지 확인합니다.
  2. 설정 → 메모 저장 폴더 → 바꾸기…에서 그 안의 새 폴더(예: Google Drive\memopin)를 고릅니다. 지금 메모가 그리로 복사됩니다.
  3. 다른 컴퓨터에서도 같은 폴더를 고르면 끝입니다. 이미 메모가 있는 폴더를 고르면 그 메모를 읽어 옵니다(합치지 않습니다).
주의할 점
  • 두 컴퓨터에서 같은 메모를 동시에 고치면 나중에 저장된 쪽이 남습니다. 서비스가 "충돌 사본"을 만들면 그 파일은 무시됩니다.
  • 구글 드라이브 "스트리밍" 모드나 OneDrive "파일 요청 시 다운로드"는 폴더를 오프라인 사용 가능으로 두어야 합니다. 안 그러면 메모가 비어 보일 수 있습니다.
  • 설정(단축키·테마 등)은 컴퓨터마다 따로이고 동기화되지 않습니다.

데이터는 어디에 있나

메모 하나가 JSON 파일 하나입니다. 백업은 폴더를 통째로 복사하면 됩니다.

Windows  %APPDATA%\com.writersroom.memopin\data\
macOS    ~/Library/Application Support/com.writersroom.memopin/data/

data/
├─ notes/<id>.json     메모 하나씩(본문 HTML, 색, 위치, 상태)
├─ images/<id>.png     이미지 메모의 그림
└─ categories.json      카테고리 목록

알려진 제한

  • 코드 서명이 없어 윈도우 SmartScreen과 맥 Gatekeeper 경고가 한 번씩 뜹니다.
  • 이미지 메모는 아직 복제가 안 되고, 파일을 끌어다 놓기도 안 됩니다(🖼 버튼이나 붙여넣기를 쓰세요).
  • 새 메모에 글을 치고 0.5초 안에 Alt+F4로 닫으면 저장 전이라 빈 메모로 사라질 수 있습니다. ✕ 버튼은 저장을 기다린 뒤 닫습니다.
  • 서식은 굵게·기울임·밑줄·취소선·세 종류 목록·체크박스가 전부입니다. 링크, 표, 글자색은 없습니다.
  • 맥은 유니버설 빌드 하나이지만 실제 사용 검증은 윈도우에서 훨씬 많이 했습니다. 이상하면 알려 주세요.
